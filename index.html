Telegram-Obsidian Sync

A powerful plugin that bridges Telegram and Obsidian, enabling seamless synchronization of messages, notes, and media. Built for knowledge workers who want their Telegram conversations integrated directly into their Obsidian vault.

Python Telegram API Obsidian Plugin Automation
GitHub
telegram_sync.py 
from telegram import Bot
from obsidian import Vault

class TelegramSync:
    def __init__(self, token):
        self.bot = Bot(token)
        self.vault = Vault()

    async def sync_messages(self):
        messages = await self.bot.fetch()
        for msg in messages:
            self.vault.create_note(msg)
        # ✅ Synced to Obsidian
